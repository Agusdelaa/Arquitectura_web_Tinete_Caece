# Arquitectura Web - CAECE

Repositorio de trabajos prácticos y presentaciones para la materia Arquitectura Web.

## Contenido
- **index.html**: Sitio web de presentación personal (CV y perfil profesional).
- **estilos.css**: Hoja de estilos del sitio web.
- **ejercicio_ajax.html**: Implementación de peticiones asincrónicas (AJAX).
- **codigo.js**: Lógica y manipulación de datos vía JavaScript.
- **assets/**: Recursos multimedia e imágenes.
